# 2026-10-16

## GetsKeeper：1.21.11 + NeoForge 21.11.41 全新 Mod（从零建成）

**背景**：仓库里原本只留着上一份 Mod（notenoughblocks / MC 26.2）的 `build.gradle` + `gradle.properties`，没有 `src/`，也没有 `gradle/wrapper/`。本次把整仓改造成 GetsKeeper。

**产物**
- 构建：`build.gradle` 换成 **ModDevGradle 2.0.124**（1.21.11 官方已弃用旧 `net.neoforged.gradle.userdev` 7.x），`gradle.properties` 指向 MC 1.21.11 / NeoForge 21.11.41 / Java 21，wrapper 用 **Gradle 9.2.0**（与 NeoForge 自身一致）。`settings.gradle` 新增。`neoforge.mods.toml` 走官方 `src/main/templates` + `generateModMetadata` 流程。
- 代码：~40 个 Java 文件，包 `top.kdxiaoyi.mod.getskeeper`，分 config / trust / item / data / source / pickup / use / security / net / client 十个模块；客户端代码同放在 main source set，靠 `@Mod(dist = Dist.CLIENT)` 隔离，不开 split source set（降低构建风险）。
- 资源：`assets/getskeeper/lang/{en_us,zh_cn}.json` 全量 key，物品贴图与图标用脚本生成的 PNG，物品模型走 1.21.4+ 的 `items/<name>.json` 新格式。
- 文档：`ARCHITECTURE.md`（模块图、数据流、持久化、1.21.11 API 变更清单、6 条有意偏离）与 `README.md`。

**关键决策**
1. 拾取事件用 `ItemEntityPickupEvent.Pre`（`EntityItemPickupEvent` 在 21.11 已不存在）。
2. 箭矢无法用事件拦截（原版在碰撞逻辑里直接入包），改为把 `AbstractArrow.pickup`（public 字段）暂置 `DISALLOWED`，取消时还原 —— 比"销毁再重放"更安全。
3. 全部形状自绘（圆角卡片/开关/按钮），只用原版经验条精灵渲染验证进度条。
4. 玩家数据用 Data Attachment（`copyOnDeath`），密码用 `SavedData`（存档颗粒度），名单用 ModConfig。

**环境问题（重要）**
`maven.neoforged.net` 在本机不可达（DNS 正常但连接超时，WebFetch 也失败），因此**无法在本环境完成编译验证**。可用镜像 `https://maven.creeperhost.net`（NeoForge Maven 的代理，metadata 可读但 jar 未缓存）。README 里已写明镜像配置方法。

**方法论沉淀（下次做 MC Mod 时直接复用）**
- NeoForge 侧：`git clone --depth 1 --branch <mc版本> https://github.com/neoforged/NeoForge.git` → `src/main/java`（common）+ `src/client/java`（client）+ `patches/`（补丁含原版上下文代码）+ `tests/`（官方示例）。
- 原版侧：`piston-meta.mojang.com` 取版本 json → 下载 `client.jar` 与 `client_mappings`（client.txt）。**client.txt 是 ProGuard 映射，逐行给出带完整参数类型的原始签名**，可直接 grep 出任意原版方法的确定性签名；`client.jar` 用于确认 GUI 精灵路径、lang、以及 `javap -p` 反查字段可见性（本次靠它确认 `AbstractArrow.pickup` 是 public）。
- 常用坑位：`ResourceLocation`→`Identifier`、`ResourceKey#location`→`#identifier`、输入事件改 `MouseButtonEvent/KeyEvent`、`blitSprite` 需 `RenderPipeline`、`SavedDataType`+Codec 取代 `SavedData.Factory`、`Commands.LEVEL_*` 变 `PermissionCheck`、Attachment 用 `MapCodec`（`CODEC.fieldOf("x")`）。
